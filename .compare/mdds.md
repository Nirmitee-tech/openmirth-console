# MDDS Console

Browser-based administration, monitoring, and peer-to-peer data exchange for Mirth Connect and Open Integration Engine.

Overview

## Mirth Connect administration  moves to the browser.

![MDDS Console monitoring dashboard with system health, throughput charts, and channel metrics](https://saga-it.com/images/products/mdds/console-dashboard-dark.webp)![MDDS Console monitoring dashboard with system health, throughput charts, and channel metrics](https://saga-it.com/images/products/mdds/console-dashboard-light.webp)

One plugin install on your Mirth Connect or OIE server. Everything else happens in the browser — no Java client, no VPN, no open ports.

The Platform

## One plugin. Three capabilities.

Install the MDDS plugin on your Mirth Connect or OIE server and unlock a modern experience layer.

### Web Administration

Full [Mirth Connect](https://saga-it.com/services/mirth-connect) administration from your browser. Channel management, message browser, DICOM viewer — no Java client needed.

### Monitoring & Alerts

PHI-free dashboard with real-time channel health, throughput metrics, error rates, and intelligent alerting — built for [healthcare integration engines](https://saga-it.com/services/healthcare-integration-engines).

### P2P Data Exchange

Secure data transfer between organizations over an encrypted peer-to-peer network. No VPN required.

How It Works

## Up and running in five minutes.

1

### Install the plugin

Add to your existing Mirth Connect or OIE server. Or download OIE with the plugin pre-installed.

2

### Open the Console

Navigate to MDDS Console in your browser. Your server appears automatically — no configuration needed.

3

### Manage everything

Administer channels, monitor health, browse messages, and exchange data — all from the browser.

Features

## Everything the Java client does. And more.

A modern experience layer for healthcare integration engines.

### Channel Management

Create, edit, deploy, and manage channels with a modern interface. Full parity with the Java Administrator.

### Message Browser

Search, filter, and inspect messages across all channels. Reprocess failed messages with one click.

### DICOM Viewer

Built-in medical image viewer for DICOM channels. View studies directly in the browser.

### Intelligent Alerting

Anomaly detection, threshold alerts, and predictive warnings before issues impact message delivery.

### Multi-Server Support

Monitor and manage all your Mirth Connect and OIE instances from a single unified console.

### Secure Remote Access

Zero-trust architecture with outbound-only connections. No VPN, no open ports, no exposed endpoints.
